# koishi-plugin-regular-expression-replacement
一个用于 **Koishi** 的正则表达式文本处理插件。
可以在消息进入后续处理流程前，根据自定义正则规则对文本进行**剔除、普通替换或随机替换**。
## 功能

### 剔除规则

通过正则表达式匹配不需要的内容，并直接将其从文本中删除。

### 普通替换

使用正则表达式匹配文本，并替换成指定内容。


### 随机替换

匹配指定文本后，从多个候选文本中**随机选择一个进行替换**。


## 正则标志

每条规则都可以单独设置 Flags。

常用 Flags：

| Flag | 作用 |
| --- | --- |
| `g` | 全局匹配 |
| `i` | 忽略大小写 |
| `m` | 多行模式 |
| `s` | 允许 `.` 匹配换行符 |
| `gi` | 全局匹配并忽略大小写 |

一般情况下推荐使用：

```text
g
```

## 规则管理

插件提供 Koishi Console 管理页面，可以直接在网页中维护规则。

支持：

- 新增规则
- 删除规则
- 单独启用/禁用规则
- 保存规则
- 导入规则
- 导出规则

修改完成后需要点击：

```text
保存更改
```

规则才会保存并生效。

---

## 正则测试工具

插件内置正则测试功能。

可以直接输入一段机器人原本准备输出的文本，然后查看经过当前规则处理后的最终结果。

使用方法：

1. 配置正则规则
2. 点击「保存更改」
3. 打开「正则测试工具」
4. 输入测试文本
5. 点击「执行替换测试」
6. 查看处理结果

这样可以在正式使用规则之前检查正则是否符合预期。

---

## 配置导入 / 导出

插件支持将全部规则导出为 JSON 文件。

可以通过管理页面的：

```text
导出配置
```

保存当前规则。

需要恢复配置时，点击：

```text
导入配置
```

选择之前导出的 JSON 文件即可。

导入成功后规则会自动保存。

## 安装

在 Koishi 插件市场搜索：

```text
regular-expression-replacement
```

或者通过 npm 安装：

```bash
npm install koishi-plugin-regular-expression-replacement
```

## 注意事项

正则表达式基于 JavaScript `RegExp` 语法。

如果填写了错误的正则表达式，可能导致对应规则无法正常执行，因此建议先通过插件自带的「正则测试工具」进行测试。

使用 `g` 全局匹配时，会替换文本中所有符合条件的内容；如果不填写 `g`，通常只会处理第一次匹配到的内容。

随机替换结果具有随机性，同一段输入文本多次处理后可能得到不同结果。
